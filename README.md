# CDU Airflow CFD

จำลองการไหลของลมร้อนจากคอยล์ร้อน (CDU) Daikin VRV 6A ในลานวางเครื่องแบบสามมิติ
หาการวนกลับของลมร้อน (hot-air recirculation) อุณหภูมิลมเข้าคอยล์รายเครื่อง และผลต่อ capacity
ทำงานในเบราว์เซอร์ทั้งหมด

## เปิดใช้งาน

**วิธีง่ายที่สุด** — ดับเบิลคลิก `dist/cdu-airflow-cfd.html` เปิดด้วย Chrome หรือ Edge
ไฟล์เดียวจบ ไม่ต้องติดตั้ง ไม่ต้องใช้เว็บเซิร์ฟเวอร์ และใช้งานออฟไลน์ได้ (คำนวณเธรดเดียว)

**ให้คำนวณเร็วที่สุด (ใช้ทุกแกนของ CPU)** — เปิดผ่านเว็บเซิร์ฟเวอร์แทนการดับเบิลคลิกไฟล์ เช่น `npm run serve`
แล้วเปิด `http://localhost:8000` (หรือ `http://localhost:8000/dist/cdu-airflow-cfd.html`) หรือวางโฟลเดอร์ `dist/`
ไว้บนเว็บโฮสต์ใดก็ได้ (เช่น GitHub Pages) เบราว์เซอร์อนุญาตให้ใช้หน่วยความจำร่วมระหว่างเธรดเฉพาะหน้าที่เปิดผ่าน
http(s) เท่านั้น — แถบสถานะด้านล่างของโปรแกรมบอกจำนวนเธรดที่ใช้อยู่

สำหรับพัฒนาโค้ด:

```
npm install
npm run serve        # แล้วเปิด http://localhost:8000
npm run build        # สร้าง dist/cdu-airflow-cfd.html ใหม่
npm run build:wasm   # คอมไพล์ src/kernels.c ใหม่ (ต้องมี clang + wasm-ld) — เฉพาะเมื่อแก้ kernels.c
npm test             # ทดสอบ solver: node tools/selftest.mjs <preset> <cell> <tEnd> [--uniform] [--threads=N] [--compare]
```

   **`O` Offset**: พิมพ์ระยะ + `Enter` → คลิกวัตถุ → คลิกฝั่งที่ต้องการ (ผนัง = สำเนาขนานห่างตามระยะ,
   CDU/อาคาร/พื้น = สำเนาเว้นช่องว่างระหว่างขอบตามระยะ เช่น ระยะ service) ทำต่อได้หลายครั้งจนกด `Esc` ·
   **`Shift+C` Copy**: เลือกวัตถุ → จุดฐาน → คลิกวางสำเนาได้หลายครั้ง (หรือพิมพ์ระยะ + `Enter`) จนกด `Esc` ·
   **`Shift+M` Mirror**: เลือกวัตถุ → คลิกสองจุดของเส้นสะท้อน → ได้สำเนาสะท้อน (ต้นฉบับคงเดิม, CDU กลับทิศหน้าเครื่องให้) ·

   ถ้าเลือกวัตถุไว้ก่อนเรียกคำสั่ง จะใช้วัตถุนั้นทันที (ข้ามขั้นเลือก) ·

2. **ปรับแต่ง** — คลิกวัตถุแล้วแก้ที่แผงด้านขวา (รุ่น ทิศหน้าเครื่อง ฐาน ท่อเป่าลม ความสูงและ % เปิดของ louver)
   ลากเพื่อย้าย · `Ctrl+Z` เลิกทำ
3. **คำนวณ** — ตั้งอุณหภูมิอากาศ ลม (ความเร็วลมเข้าเท่ากันทั้งระนาบขอบต้นลม) ขนาดเซลล์ แล้วกด `▶ คำนวณ` — หยุดเองเมื่อผลนิ่ง
4. **อ่านผล** — ตัวเครื่องแต่ละโมดูลเปลี่ยนสีตาม T ลมเข้าเฉลี่ย (เขียว ≤ 40 °C · เหลือง > 40–46 °C · แดง > 46 °C ที่อากาศภายนอก 35 °C ปรับเกณฑ์ได้) ·
   ตารางรายเครื่อง (T ลมเข้า, ΔT, % ลมวนกลับ, capacity), ระนาบหน้าตัดสี, ผิวลมร้อน,
   อนุภาคลม, กราฟ T ลมเข้าตามเวลา, ข้อเสนอแนะการแก้ไข และตารางเปรียบเทียบทางเลือก
   · แผง **การแสดงผล**: เลือกรูปแบบกราฟิกบนระนาบหน้าตัด **Contour / Streamline / Vector** และตัวแปรที่ใช้ระบายสี
   (อุณหภูมิ ΔT ความเร็ว ความดันเทียบบรรยากาศ สัดส่วนลมร้อน) · ปรับ **ความทึบของวัตถุ** (ทึบ ↔ โปร่ง) เพื่อมองทะลุเครื่องและผนัง ·
   ภาพเคลื่อนไหว (อนุภาคลม แสงวิ่งตาม streamline) หยุดนิ่งเป็นค่าเริ่มต้น กด **▶ เล่นภาพเคลื่อนไหว** มุมขวาล่างเพื่อเล่น/หยุด ·
   **คลิกที่คอยล์ร้อน** เพื่อดู No. CDU รุ่นเครื่อง และอุณหภูมิลมกลับ (รวมรายโมดูล)
   · มุมมอง **3D / เหนือ / ใต้ / ออก / ตก** (3 มิติจากแต่ละทิศ) และ **Top** (ภาพฉายจากด้านบน) — ปุ่มลัด 1–6 · ปุ่ม **⛶ เต็มจอ** ยังมีแถบเครื่องมือ (+CDU / ผนัง / อาคาร / พื้น-หลังคา) และแผงแก้วัตถุให้ใช้ต่อ ·
   ความทึบของวัตถุปรับเฉพาะผนัง อาคาร พื้น/หลังคา — CDU ทึบเสมอ · Contour แสดงละเอียดกว่าเมช (แทรกค่าแบบ bilinear) ·
   **📷 Capture** (คีย์ `P`) เก็บภาพหลายมุมพร้อมแถบสี แก้คำบรรยายได้ และทุกภาพจะอยู่ในรายงาน HTML
5. **ส่งออก** — บันทึกโปรเจกต์ `.json`, ผลเป็น CSV, รายงาน HTML พร้อมภาพ 3D

## เมชและเวลาคำนวณ

เมชเป็นกริด rectilinear แบบ **ปรับความละเอียดอัตโนมัติ** (ค่าเริ่มต้น — `src/grid.js`): ใช้เซลล์ขนาดที่เลือกเฉพาะ
บริเวณที่ผลขึ้นกับความละเอียดจริง ๆ แล้วขยายเซลล์ออกไปไม่เกิน 20% ต่อเซลล์จนถึง 8 เท่า (ไม่เกิน 1 ม.) ที่ขอบโดเมน

- รอบ CDU 0.6 ม. และเหนือปากพัดลม 1.2 ม. — เซลล์ขนาด h วางบนแลตทิซเดียวกับเมชสม่ำเสมอ ตัวเครื่อง ผนัง และช่องว่าง
  รอบเครื่องจึงถูกแปลงเป็นเซลล์เหมือนเมชสม่ำเสมอทุกประการ
- ขอบผนัง / louver / อาคาร / แผ่นพื้นที่อยู่ใกล้เครื่อง (≤ 1 ม.) — ขนาด h เช่นกัน · ที่ไกลกว่านั้น 2h
- เครื่องที่ถูกล้อมด้วยของสูงกว่า (ช่องแคบระหว่างอาคาร คอกผนังสูง ใต้หลังคา ในระยะ 3 ม.) — คงขนาด h ในแนวดิ่ง
  ขึ้นไปถึงยอดสิ่งที่ล้อม เพราะลมร้อนวนกลับลงมาในช่องนั้น
- โดเมน ระยะเผื่อ และเงื่อนไขขอบเหมือนเมชสม่ำเสมอ เลือก **รูปแบบเมช → สม่ำเสมอ** ได้ถ้าต้องการเซลล์เท่ากันทั้งโดเมน

จำนวนเซลล์ของตัวอย่างสำเร็จรูป (สม่ำเสมอ → ปรับความละเอียดอัตโนมัติ):

| เซลล์ | ดาดฟ้า 6 ชุด | ช่องแคบระหว่างอาคาร | ลานพื้นดิน + ลม |
|---|---|---|---|
| 0.50 ม. | 36k → 26k | 40k → 26k | 36k → 25k |
| 0.25 ม. | 278k → 102k (÷2.7) | 323k → 118k (÷2.7) | 281k → 123k (÷2.3) |
| 0.10 ม. | 4.30M → 0.83M (÷5.2) | 5.04M → 1.09M (÷4.6) | 4.35M → 0.96M (÷4.5) |

ความแม่นยำเทียบเมชสม่ำเสมอขนาดเซลล์เดียวกัน (T ลมเข้าเฉลี่ยตามเวลาช่วง 100–300 s รายเครื่อง):

| กรณี | เมชสม่ำเสมอ | ปรับความละเอียดอัตโนมัติ | ต่างกันมากสุด |
|---|---|---|---|
| ช่องแคบ 0.35 ม. | 43.48 / 39.73 / 37.73 / 35.52 °C | 43.58 / 39.84 / 37.80 / 35.54 °C | 0.11 K |
| ช่องแคบ 0.25 ม. | 43.96 / 39.99 / 37.73 / 36.21 °C | 44.05 / 40.10 / 37.77 / 36.22 °C | 0.11 K |
| ดาดฟ้า 0.35 ม. | 35.11–35.35 °C | 35.10–35.29 °C | 0.06 K |
| ดาดฟ้า 0.25 ม. | 35.18–35.38 °C | 35.10–35.28 °C | 0.15 K |
| ลานพื้นดิน + ลม 2 m/s 0.35 ม. (ไม่นิ่ง ±0.2 K) | 35.62–35.78 °C | 35.42–35.73 °C | 0.20 K |

ผลต่างอยู่ในระดับเดียวกับ (หรือน้อยกว่า) ผลของการเปลี่ยนขนาดเซลล์หนึ่งขั้น (0.35 → 0.25 ม. เปลี่ยน T ลมเข้าได้ถึง 0.7 K)

เวลาคำนวณจนลู่เข้า ตัวอย่างดาดฟ้า 6 ชุด (วัดด้วย `tools/selftest.mjs` บนเครื่อง 4 แกน — เบราว์เซอร์ใกล้เคียงกัน):

| เซลล์ | รุ่นก่อน (สม่ำเสมอ เธรดเดียว) | รุ่นนี้ เธรดเดียว (เปิดไฟล์ตรง ๆ) | รุ่นนี้ 4 เธรด (เปิดผ่าน http) |
|---|---|---|---|
| 0.35 ม. | 105k เซลล์ · 28 วินาที | 47k เซลล์ · 13 วินาที | 5 วินาที |
| 0.25 ม. | 278k เซลล์ · 1 นาที 41 วินาที | 102k เซลล์ · 41 วินาที | 15 วินาที |
| 0.10 ม. (ค่าเริ่มต้น) | 4.30M เซลล์ · ราว 75 นาที (ประมาณจากเวลาต่อสเต็ป) | 0.83M เซลล์ · ราว 12 นาที | ราว 4–5 นาที |

เครื่องที่มีแกนมากกว่านี้จะเร็วขึ้นอีก (จำกัดด้วยความเร็วหน่วยความจำ — 4 เธรดเร็วกว่าเธรดเดียวราว 3 เท่า)

## แบบจำลองเชิงตัวเลข (`src/solver.js`, `src/kernels.c`)

- Navier–Stokes แบบอัดตัวไม่ได้ บนกริด rectilinear แบบ staggered (MAC) + Boussinesq — เซลล์กว้างไม่เท่ากันได้
- โมเมนตัม: Semi-Lagrangian · ความดัน: projection + Red-Black SOR (warm start, ปรับรอบอัตโนมัติ)
- ความปั่นป่วน: Smagorinsky (Cs = 0.17, Δ = (Δx·Δy·Δz)^⅓)
- อุณหภูมิและ tracer: finite volume แบบอนุรักษ์ MUSCL/van Leer — สมดุลพลังงานตรวจได้ในแผงคุณภาพ
- CDU: หน้าคอยล์ (หลัง/ซ้าย/ขวา) ดูดลม, พัดลมด้านบนเป่าลม, ความร้อนทิ้งขึ้นกับ T ลมเข้าแบบป้อนกลับ
- Louver: ตัวกลางพรุน K = (1/(Cd·φ) − 1)²
- Δt จากอัตรา CFL สูงสุด max(|u|/Δx) ≤ 1.5 — เซลล์ใหญ่ที่อยู่ไกลเครื่องไม่ทำให้ Δt เล็กลง
- เกณฑ์ลู่เข้า: T ลมเข้าทุกเครื่องเปลี่ยน ≤ ±0.05 °C ระหว่างช่วง 10 วินาที และสมดุลพลังงาน 95–105%

### ความเร็วและหน่วยความจำ

ลูปหนักทั้งหมด (advection, turbulence, diffusion, projection/SOR, การพาอุณหภูมิ, residual) อยู่ใน `src/kernels.c`
คอมไพล์เป็น WebAssembly สองแบบและฝังไว้ใน `src/kernels-wasm.js`

- **หลายเธรด** — ทุกลูปแบ่งตามชั้น k ให้เธรดละช่วง เธรดช่วยงานเป็น Web Worker บนหน่วยความจำร่วม
  (SharedArrayBuffer + atomics) ใช้ทุกแกนของเครื่อง (เว้นหนึ่งแกนให้หน้าจอเมื่อมีมากกว่า 4 แกน, สูงสุด 16 เธรด)
  ผลรวมและค่าสูงสุดเก็บแยกตามชั้นแล้วรวมตามลำดับเดิมเสมอ ผลจึง **ตรงกันทุกบิตไม่ว่าจะใช้กี่เธรด**
  (`node tools/selftest.mjs rooftop 0.35 10 --compare` ตรวจให้)
  เบราว์เซอร์ให้ใช้หน่วยความจำร่วมเฉพาะหน้าที่เป็น cross-origin isolated: เมื่อเปิดผ่าน http(s)
  service worker `coi-sw.js` จะเติมส่วนหัว COOP/COEP ให้เองแล้วโหลดหน้าใหม่หนึ่งครั้ง ไม่ต้องตั้งค่าเซิร์ฟเวอร์
  เปิดไฟล์ด้วย `file://` ทำไม่ได้ จึงคำนวณเธรดเดียว
- **หน่วยความจำ ≈ 75 ไบต์ต่อเซลล์** (เดิม 112 + สำเนานอก WebAssembly อีก 16): ฟลักซ์ของการพาอุณหภูมิส่งต่อผ่านบัฟเฟอร์
  ขนาดหนึ่งระนาบแทนอาร์เรย์สะสมเต็มกริด, ความเร็วที่กำหนดที่ขอบเก็บเป็นรายการเฉพาะหน้า, บัฟเฟอร์ความเร็วสลับแทนการคัดลอก
  รวมกับเมชที่เล็กลง ตัวอย่างดาดฟ้าที่เซลล์ 0.10 ม. ใช้ราว 64 MB จากเดิมราว 550 MB — เพดาน 4 GB ของ WebAssembly
  จึงรองรับงานที่ใหญ่กว่าเดิมมาก
- เมชใหญ่ส่งสนามค่าไปแสดงผลห่างขึ้น (ราว 0.4 วินาทีต่อล้านเซลล์) ไม่ให้การคัดลอกถ่วงการคำนวณ

การ์ดจอ (GPU) ยังไม่ถูกใช้คำนวณ — ใช้เฉพาะวาดภาพ 3 มิติ

ตารางรุ่นใน `src/models.js` (kW, อัตราลม, ขนาด, ชุดผสม 8–78 HP) มาจาก catalog EDTRTH342529A
ส่วน EER 3.5 และ capacity ลดลง 2 %/°C เป็นค่าประมาณ แก้ได้ในโปรแกรม
ผลใช้เปรียบเทียบผังการวางเครื่อง ไม่ใช่ผลรับรองทางวิศวกรรม

```
index.html            หน้าจอ (โหมดพัฒนา)

src/mesher.js         แปลงฉากเป็นกริด + เงื่อนไขขอบของ CDU

src/kernels-wasm.js   WebAssembly ที่คอมไพล์แล้ว เธรดเดียว + หลายเธรด (สร้างโดย tools/build-wasm.mjs)
src/kernels.js        โหลด WebAssembly จองหน่วยความจำ และสร้างเธรดช่วยงาน

src/engine.js         ตัวเดินสเต็ป (ใช้ทั้งใน worker และ main thread)
src/worker.js         Web Worker
src/runner.js         เลือก worker / main thread อัตโนมัติ
tools/build.mjs       รวมเป็นไฟล์เดียว dist/cdu-airflow-cfd.html
tools/build-wasm.mjs  คอมไพล์ src/kernels.c เป็น src/kernels-wasm.js
tools/selftest.mjs    ทดสอบ solver จาก command line
vendor/three/         three.js r160
```
