# AirFlow Studio — CFD Simulation สำหรับงานเครื่องปรับอากาศ

เว็บแอปจำลองการไหลของอากาศและการกระจายความเย็นสามมิติ สำหรับงานออกแบบระบบปรับอากาศ
ทั้งภายในห้อง (Indoor unit) และภายนอกอาคาร (Outdoor unit / คอยล์ร้อน)

หน้าตาและลำดับการทำงานออกแบบตามโปรแกรมที่วิศวกรคุ้นเคย — วางรูปทรงแบบ SpaceClaim
แล้วตั้งเงื่อนไข คำนวณ และดูผลแบบ Ansys CFX — แต่ทำงานได้ทั้งหมดในเบราว์เซอร์
ไม่ต้องติดตั้งอะไรเลย

```
เปิดไฟล์ index.html ด้วยเบราว์เซอร์ หรือเสิร์ฟด้วยเว็บเซิร์ฟเวอร์ใดก็ได้:

    python3 -m http.server 8000
    # แล้วเปิด http://localhost:8000
```

ต้องต่ออินเทอร์เน็ตครั้งแรกเพื่อโหลดไลบรารี three.js จาก CDN

## ขั้นตอนการใช้งาน

แถบเมนูด้านบนเรียงตามลำดับการทำงานจริง

| แท็บ | ใช้ทำอะไร |
|---|---|
| **🧊 แบบจำลอง** | เลือกโหมด Indoor/Outdoor, ตั้งขนาดห้อง, วางเครื่องปรับอากาศและสิ่งกีดขวาง |
| **⚙️ เงื่อนไข** | อุณหภูมิเริ่มต้น, ความเร็ว/ทิศทางลมธรรมชาติ (โหมด Outdoor), ความละเอียดเมช |
| **▶️ คำนวณ** | เริ่ม/พัก/รีเซ็ตการคำนวณ และดูสถานะ |
| **📊 ผลลัพธ์** | ระนาบตัดสี, เวกเตอร์ลม, อนุภาคลม, สเกลสี และสรุปผล |

ทางลัด: ลากวัตถุใน 3D เพื่อย้ายตำแหน่ง · `R` หมุน 90° · `Delete` ลบ · `Esc` ยกเลิกการเลือก · `เว้นวรรค` เริ่ม/พักการคำนวณ

เริ่มเร็วที่สุดคือเลือก **ตัวอย่างสำเร็จรูป** ในแท็บแบบจำลอง แล้วกดเริ่มคำนวณ

## อุปกรณ์ที่มีให้

| อุปกรณ์ | จำลองอะไร |
|---|---|
| 🌬️ แอร์ติดผนัง | ช่องจ่ายลมด้านหน้าล่างปรับมุมบานเกล็ดได้ กริลลมกลับด้านบนเครื่อง |
| ✳️ คาสเซ็ท 4 ทิศทาง | ช่องจ่ายลม 4 ด้านรอบขอบ ดูดลมกลับตรงกลางฝ้า |
| 🗄️ แอร์ตั้งพื้น | จ่ายลมด้านบนเฉียงขึ้น ดูดลมกลับด้านล่าง |
| 🔥 คอยล์ร้อน (CDU) | เป่าลมร้อนออกด้านหน้าหรือด้านบน ดูดอากาศเข้าด้านหลัง |
| 📦 สิ่งกีดขวาง | เฟอร์นิเจอร์ ผนัง รั้วบังตา ชั้นวางของ |
| ♨️ แหล่งความร้อน | คน ไฟส่องสว่าง เครื่องจักร (ระบุเป็นวัตต์) |

เครื่องปรับอากาศตั้งได้ทั้งขนาด BTU, อัตราลม, มุมบานเกล็ด, อุณหภูมิที่ตั้งไว้
และเลือกได้ว่าจะให้คำนวณอุณหภูมิลมจ่ายจากขนาด BTU หรือกำหนดเอง

## ผลลัพธ์ที่อ่านได้

**ภายในห้อง** — อุณหภูมิห้องเฉลี่ย, อุณหภูมิที่ระดับคนอยู่อาศัย (0.1–1.8 ม.),
ความไม่สม่ำเสมอของอุณหภูมิ, สัดส่วนพื้นที่ที่อยู่ในช่วงสบาย 22–26 °C,
และสัดส่วนพื้นที่เสี่ยงลมโกรก (ความเร็วลมเกิน 0.25 m/s)

**ภายนอกอาคาร** — อุณหภูมิอากาศที่ไหลเข้าคอยล์ร้อนแต่ละตัวเทียบกับอากาศภายนอก
ซึ่งเป็นตัวชี้วัดการวนกลับของลมร้อน (short-circuit) ที่ทำให้คอยล์ทำงานหนักและตัดการทำงาน

เลือกเครื่องใดเครื่องหนึ่งแล้วดูแผงคุณสมบัติด้านขวา จะเห็นอุณหภูมิลมกลับ ลมจ่าย
สถานะคอมเพรสเซอร์ และกำลังทำความเย็นที่ทำได้จริงขณะนั้น

## แบบจำลองเชิงตัวเลขที่ใช้

`js/solver.js` แก้สมการ Navier-Stokes แบบอัดตัวไม่ได้บนกริดสม่ำเสมอ

| ส่วน | วิธีที่ใช้ |
|---|---|
| การพา (advection) | Semi-Lagrangian — เสถียรทุกขนาดสเต็ปเวลา |
| ความดัน | Poisson projection แก้ด้วย SOR (ω = 1.7) |
| แรงลอยตัว | Boussinesq approximation |
| ความปั่นป่วน | Eddy viscosity คงที่ 0.02 m²/s |
| พลังงาน | สมการการพาความร้อน + สมดุลพลังงานรวมของโดเมน |

### สามจุดที่ต้องระวังเป็นพิเศษ และวิธีจัดการ

**1. ผนังต้องเป็นฉนวนจริง** — ถ้าปล่อยให้การ interpolate ของ semi-Lagrangian
หยิบอุณหภูมิจากเซลล์ของแข็งมาด้วย ผนังจะกลายเป็นแหล่งความร้อนที่ไม่มีวันหมด
(ค่าถูกคัดลอกเข้ามาโดยตัวผนังไม่เย็นลงเลย) ห้องจึงไม่มีวันเย็น
`advectTemp()` จึงตัดน้ำหนักของเซลล์ของแข็งออกแล้วหารกลับ

**2. ความเร็วลมที่หัวจ่ายต้องเท่าของจริง** — บนกริดหยาบ หนึ่งเซลล์กว้างกว่าช่องจ่ายลมจริง
หลายเท่า ถ้าใช้พื้นที่ของเซลล์ตรง ๆ ลมจะออกช้าเกินจริงจนพุ่งไม่ถึงกลางห้องและถูกดูดกลับ
เข้าเครื่องทันที `addFlowRegion()` จึงย่อจำนวนเซลล์ของหน้ากริลลงให้ใกล้พื้นที่หน้ากริลจริง
ของอุปกรณ์ ได้ทั้งอัตราลม (m³/h) และความเร็วลม (m/s) ที่ถูกต้องพร้อมกัน

**3. สมดุลพลังงานต้องบังคับ** — semi-Lagrangian ไม่ใช่วิธีที่อนุรักษ์ปริมาณรวม และ
เงื่อนไขขอบแบบกำหนดอุณหภูมิลมจ่ายก็ไม่ได้หักพลังงานที่อากาศพาออกไปทางลมกลับ
ผลคือห้องเย็นลงช้ากว่าที่เครื่องขนาดนั้นทำได้จริงราวห้าเท่า `balanceEnergy()` จึงวัด
พลังงานที่เปลี่ยนไปจริงในแต่ละสเต็ป เทียบกับที่ควรเป็น (กำลังเครื่อง + ภาระความร้อน)
แล้วเกลี่ยส่วนต่างกลับเข้าไปโดยถ่วงน้ำหนักตามความเร็วลม — บริเวณที่ลมพัดถึงได้รับผลมาก
มุมอับลมแทบไม่เปลี่ยน รูปแบบการกระจายจาก CFD จึงยังคงอยู่ ขณะที่ระดับอุณหภูมิรวม
ถูกต้องตามหลักเทอร์โมไดนามิกส์

### ข้อจำกัดที่ควรทราบ

- เป็นการจำลองเชิงแนวคิดเพื่อเปรียบเทียบทางเลือกการวางเครื่อง ไม่ใช่ผลรับรองทางวิศวกรรม
  และไม่ทดแทนการคำนวณโหลดตามมาตรฐาน
- ใช้ eddy viscosity คงที่ ไม่ใช่แบบจำลองความปั่นป่วนเต็มรูป (k-ε, SST) อย่างใน CFX
- ไม่คิดความชื้น ความร้อนแฝง และการแผ่รังสี — คิดเฉพาะความร้อนสัมผัส
- ผนังห้องเป็นฉนวนสมบูรณ์ ไม่มีความร้อนผ่านผนังหรือกระจก ให้ใส่เป็นแหล่งความร้อนแทน
- ยิ่งเมชละเอียดยิ่งใกล้ของจริง แต่ช้าลงมาก จำกัดที่ประมาณ 600,000 เซลล์

## โครงสร้างไฟล์

```
index.html        โครงหน้าจอ: ริบบอน โครงสร้างแบบจำลอง วิวพอร์ต แผงคุณสมบัติ
css/style.css     ธีมมืดแบบโปรแกรมวิศวกรรม
js/solver.js      เครื่องคำนวณ CFD สามมิติ
js/devices.js     คลังอุปกรณ์ และการแปลงอุปกรณ์เป็นเงื่อนไขขอบของ CFD
js/viewer.js      การแสดงผลสามมิติด้วย three.js (ระนาบตัด เวกเตอร์ อนุภาค การลากวัตถุ)
js/presets.js     ตัวอย่างงานสำเร็จรูป
js/main.js        ตัวควบคุมหลัก เชื่อม UI เข้ากับ solver และ viewer
```

โปรเจกต์บันทึกและเปิดกลับเป็นไฟล์ `.json` ได้จากปุ่มมุมขวาบน
